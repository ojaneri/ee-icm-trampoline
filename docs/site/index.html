ICM — Instrument Cluster Module

Protótipo de painel automotivo com Trampoline RTOS (OSEK/VDX) rodando em hardware real.

Equipe: Osvaldo Janeri Filho · Norton Dezonet · Vinicius Antunes

📱 Simulação do Display LCD (ESP32-C6)

O firmware roda 6 telas em auto-rotação (5s). Clique nos botões abaixo para simular a navegação ou pressione BOOT na placa física.

GAUGES [1/6]
STATUS: NORMAL

📶 Como Conectar (Wi-Fi Dashboard)

A ESP32-C6 cria seu próprio Access Point. Siga os passos:

SSID: ICM-Dashboard-AP

Senha: 12345678

Acesse: http://192.168.4.1

No celular ou PC, você verá gráficos interativos (Canvas), abas navegáveis e dados atualizados em tempo real via WebSocket.

⚙️ Hardware Validado

  • ESP32-C6 DevKitC-1: Display ST7789 1.47" TFT, Wi-Fi 6, WebSocket Server.
  • STM32 Nucleo L476RG: Validação do escalonamento OSEK e proteção de recursos em ARM Cortex-M4.

Reproduzir o Experimento

# Instalar PlatformIO e gravar firmware
platformio run -d esp32_dashboard --target upload
